# Verilog RTL Design & Verification Hub

A production-grade, synthesizable Verilog HDL portfolio targeting FPGA, ASIC, and SoC architectures. This repository covers synchronous storage buffers, industry-standard serial communication engines, high-speed DSP frequency synthesizers, and on-chip bus interconnect protocols.

Each subsystem includes fully synthesizable RTL code, comprehensive self-checking testbenches, and verified timing simulations executed via Icarus Verilog and EPWave.
